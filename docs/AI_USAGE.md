# AI 사용 및 검토 기록

## 도구와 요청

도구: Codex. 요청: 수업 자료와 과제2 요구사항에 맞는 주제를 정하고, 함수별 역할 분리·디자인 패턴·기본판과 개선판의 동작 보존·작은 변경·웹 화면·GitHub 가산점을 갖춘 결과물을 작성한다.

## 지원받은 범위

주제 선정, 세 CSV 양식의 가상 예제 설계, 기본판·개선판·변경판 코드, 웹 화면, 검사 코드, 예상값, README와 보고서 작성에 AI 지원을 사용했다. 보고서의 표와 검사 상수도 AI 지원으로 작성했으며 학생 개인의 독립 예측 이력으로 주장하지 않는다.

## 검토 기준과 채택한 내용

- 형식별 다른 열·날짜·금액 표기를 Adapter가 공통 형태로 변환하도록 하고, 유효성 검사와 합계 계산은 분리했다.
- 기본판에도 읽기 쉬운 함수를 사용하고, 개선판은 역할을 모듈로 나누는 데 집중했다.
- 예상 합계는 입력 예제에서 따로 계산한 상수로 두어 실제 계산 결과를 다시 예상값으로 사용하는 순환 검사를 피했다.
- 정상·경계·오류를 세 버전에 적용하고 저장 결과와 실패 후 파일 상태도 확인한다.
- 최종판의 bank 지원은 의도적 기능 추가로 기록하며, 기존 양식의 결과는 유지되는지 재검사한다.
- 웹 화면은 실제 최종 Python 처리 함수를 호출하고 저장된 결과를 다운로드한다.

## 실행 근거

`evidence/test_results.json`과 `.md`는 `python check_all.py`가 실제 실행 후 생성한다. 웹 검증 근거는 `evidence/`의 별도 기록에 남긴다. 검증이 실패하면 성공으로 덮어쓰지 않고 해당 결과를 수정·재검사한다.

## 제출자가 직접 확인할 내용

아래 사항은 자동 검사와 별개로 본인이 직접 확인해야 한다. 실행하지 않은 것을 실행했다고, AI가 작성한 것을 독립적으로 작성했다고 기록하지 않는다.

1. README대로 검사와 웹 화면을 실행한다.
2. 날짜·금액 한 값을 바꾼 예제를 실행하고 예상 결과와 실제 결과를 비교한다.
3. Adapter가 바꾸는 부분과 공통 검사·집계가 유지되는 이유를 자신의 말로 설명한다.
4. 직접 수정하거나 채택한 부분이 있으면 실제 내용·이유·실행일을 여기에 추가한다.
