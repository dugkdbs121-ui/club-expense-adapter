# 웹 동작 확인 기록

2026-11-18에 Codex의 브라우저 도구로 실제 로컬 웹 화면을 조작했다. 학생 본인이 직접 수행한 기록으로 주장하지 않는다.

1. 동아리 예제를 불러오고 실행: 전체 20,000원, 3건, 간식 16,500원, 문구 3,500원 표시. `web_success.jpg`.
2. 보고서 내려받기: 실제 JSON 파일 다운로드 후 서버 저장 파일과 내용이 같은지 검사했다.
3. 파일 선택으로 `club_invalid_amount.csv`를 업로드하고 실행: 금액 오류 표시, 결과와 다운로드 버튼 숨김. `web_error.jpg`.
4. 은행 예제로 바꿔 실행: 새 날짜·금액 표기가 같은 20,000원 결과로 변환됨. `web_bank.jpg`.

`python check_web.py`는 이와 별도로 실제 HTTP 요청을 보내며, 세 양식·다운로드·오류 후 저장 보존·크기 제한·없는 경로를 검사한다. 측정 결과는 `web_test_results.json`에 기록한다.
